# Xem TV / IPTV

> Các APK BeeTV, MonsterTV, SportsTV, IPTV Pro (mod) trong thư mục là file lưu trữ cũ, chưa xác minh malware, license hay còn chạy. Không nên cài đặt nguồn không rõ.

| Phần mềm / nguồn | Dùng để làm gì? |
|---|---|
| [VLC](https://www.videolan.org/) | Phát M3U, M3U8, video và âm thanh |
| [mpv](https://github.com/mpv-player/mpv) | Trình phát video hiệu năng cao |
| [Jellyfin](https://github.com/jellyfin/jellyfin) | Máy chủ thư viện media cá nhân |
| [iptv-org](https://github.com/iptv-org/iptv) | Danh mục stream truyền hình công khai |
| [Vietnam M3U](https://iptv-org.github.io/iptv/countries/vn.m3u) | Playlist kênh Việt Nam, phải thử từng luồng |

Để xem một playlist mà bạn có quyền sử dụng, mở VLC → Media → Open Network Stream. File M3U tải được không chứng minh kênh đang phát.

Link tải APK, kho xem phim hoặc phát bóng đá trôi nổi từ README 2023 đã được rút khỏi danh mục mới. Có thể xem lịch sử Git để khôi phục khi tự xác minh.
